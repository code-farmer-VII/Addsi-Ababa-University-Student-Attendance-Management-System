# 📚 Student Attendance Management System

A mobile application built for **Addis Ababa University** to streamline student attendance tracking, registration, and data management. This app leverages modern technologies like **QR code scanning** and **Excel file integration** to make attendance and student data handling efficient and user-friendly.

---

## 🚀 Features

### 🔖 Student Registration
- **Batch Registration**: Upload an Excel file containing student details for quick registration.
- **Manual Registration**: Add students individually through an intuitive form.
- **QR Code Integration**: Use QR codes for efficient student registration.

### ✅ Attendance Tracking
- Record attendance by scanning QR codes linked to student IDs.
- Search students using QR code scans.
- Automatically save attendance data in the database.

### 📊 Teacher Dashboard
- Retrieve attendance details:
  - Number of classes attended.
  - Student-specific information.
- Export attendance records as Excel files.

### 💾 Data Storage & Management
- Centralized database (powered by **Supabase**) to store:
  - Student information.
  - Attendance records.

### 🌟 User Interface
- Built with **React Native** and **Expo** for cross-platform compatibility.
- Styled with **Tailwind CSS** for a clean, responsive design.

---

## 🛠️ Technology Stack

### **Frontend**
- **React Native** with **Expo** for a seamless mobile app experience.
- **Tailwind CSS** for modern, responsive UI styling.

### **Backend**
- **Supabase** as Backend as a Service (BaaS) for:
  - Authentication.
  - Database management.

### **Other Tools**
- **QR Code Integration** for student ID scanning and attendance.
- **Excel Integration** for batch student registration and data export.

## 📦 Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/student-attendance-management.git
   cd student-attendance-management
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the App**:
   ```bash
   expo start
   ```

4. **Set Up Backend**:
   - Create a project on [Supabase](https://supabase.io/).
   - Configure your database tables for students and attendance records.
   - Update the Supabase API URL and Key in your project’s configuration file.
